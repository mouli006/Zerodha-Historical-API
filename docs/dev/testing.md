# Testing

What every test file covers, the fakes and fixtures they use, and the conftest rules (trim/derive OFF,
no bhavcopy fetch). Tests never touch the network or the real `.env`.

No test may hit Kite or NSE over the network. No linter is configured.

## Session `.env`
- `tests/conftest.py` sets `config.ENV_PATH` to a `.env` in a temp folder (`tempfile.mkdtemp()`) **before** it imports `dashboard`/`dhan`/`nifty_daily` (which import `app`), so every `load_env()` / `save_env()` / `secret_key()` during the run uses that file; the folder is removed at session end (`pytest_sessionfinish`, `atexit` as a fallback). `load_env`/`save_env` read `ENV_PATH` at call time, so the attribute is enough.
- The per-test stubs of `load_env`/`save_env` still apply for tests that need specific values.
- `tests/test_env_isolation.py` guards it: `ENV_PATH` is not `<repo>/.env`, and importing `app` / `secret_key()` / `save_env()` leave `<repo>/.env` unchanged (compared by existence, mtime and size only; the real file is never opened).
- The two subprocess tests in `tests/test_fno.py` (TZ, lock) only import `backfill.fno` and never load `.env`.

## Checking routes and previewing pages
- To check routes quickly, use Flask's test client: `from app import app; c = app.test_client(); c.get('/')`. Importing `app` calls `config.secret_key()`, which creates or updates the `.env` at `config.ENV_PATH`: in tests that is the session file (see "Session `.env`"), outside tests the real one.
- Pages behind login can be rendered without Kite by faking the session: `with c.session_transaction() as s: s["access_token"] = "x"; s["user"] = {...}`. To preview the UI in a browser, run a scratch script that imports `app`, adds a route setting those session keys, and fills `backfill.job.JOB` with sample values, then serves on another port (e.g. 5001). Do not start a real download from it. For screenshots, also override `auth.credentials` to return `("", "")` so the sign-in page doesn't show the saved key.

## Adding a test
- Put it in `tests/test_<topic>.py`; reuse the fakes above (`FakeKite`, fake `requests`, `FakeSession`/`FakeBrowser`) and the conftest fixtures (`trim_on`, `derive_on`).
- Stub `load_env`/`save_env`/`keep_zero_volume` wherever a route or CLI reads them; never depend on a real token, never make a network call.
- `tests/test_equity_imports.py` scans `backfill/equity/**/*.py` with `ast` and fails on any import of `backfill.fno*`, `backfill.bhav*`, `backfill.dhan_api`, `dhan`, `nifty_*` or `fno_store`; its checker is also tested on sample sources so it is not vacuous while the package is nearly empty.
- New tests are added, never weakened: run the full `pytest` before and after and compare the count.
